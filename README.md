# MailNews

Briefings d’actualité personnels envoyés par e-mail.

## Sujets
- Économie française, européenne et internationale.
- Cryptomonnaies.
- Grandes entreprises mondiales.

## Fréquence prévue
- Économie et cryptomonnaies : matin et soir, tous les jours.
- Grandes entreprises : une fois par semaine.

## Objectifs
- Briefings en français avec liens vers les sources.
- Sources francophones et anglophones.
- Réception sur une adresse ik.me.
- Sujets et horaires modifiables.
- Fonctionnement dans les limites des offres gratuites.

## Sécurité
Aucun mot de passe, jeton ou clé API dans les fichiers publics.
